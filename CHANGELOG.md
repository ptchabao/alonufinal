# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-05-23

### Added
- Initial release of ALONU app
- User authentication (login/register/logout)
- JWT token-based security with automatic refresh
- Artisan discovery and browsing with search and filters
- Service catalog with detailed service information
- Order management system
- Payment integration (Flooz, TMoney)
- Real-time order tracking
- User profile management
- Push notifications for order updates
- Multi-language support (English, French)
- Dark mode support
- Rating and review system
- Location-based artisan search
- Secure token storage
- Comprehensive error handling
- Offline support with local caching

### Technical
- Flutter 3.11.0 with Riverpod state management
- Clean Architecture implementation
- GoRouter for navigation and deep linking
- Dio HTTP client with interceptors
- Firebase integration for notifications and analytics
- Hive for local data persistence
- JSON serialization with build_runner
- Comprehensive API documentation
- Build and deployment guides
